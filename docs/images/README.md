# 图片说明

本目录目前是 **SVG 示意图**，不是真实截图。

| 文件 | 内容 |
|---|---|
| `council-flow.svg` | 五席位独立提案 → 匿名互评 → 加权收敛 → 执行 → 验收 |
| `council-output.svg` | 最终报告结构示意（议题、席位表、结论、下一步、存档） |

## 为什么用示意图

- 议会没有固定 UI，输出是 Markdown，截图反而看不清结构；
- 示意图能突出“信息放在哪、读者先看什么”；
- SVG 体积小、可缩放、GitHub 直接渲染。

## 规范

1. 图中数据必须标“示例/合成”，不能冒充真实评审结论。
2. 不出现私有 provider、真实模型绑定、真实项目名、内部路径。
3. 要补真实终端输出截图时，命名 `shot-01-report.png`，并打码路径中的用户名。

> 不要用 AI 生成“假截图”冒充真实运行结果。示意图可以，伪造截图不行。
